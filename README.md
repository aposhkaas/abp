# CRM Z1 для 1С:Предприятия 8.3 (учебная версия)

Учебная конфигурация по заданию Z1. Реализованы продажи, маркетинг и сервис в одной информационной базе.

## Что реализовано

- разделы `Продажи`, `Маркетинг`, `Сервис`;
- справочник клиентов с источником появления, обязательными телефоном и электронной почтой, комментарием и табличными частями для нескольких телефонов/адресов;
- подчиненный справочник контактных лиц с ролью и признаком основного контакта;
- документ `Взаимодействие`: клиент, отфильтрованное контактное лицо, вид, содержание, результат, следующее взаимодействие, напоминание и признак выполнения;
- кликабельные пользовательские напоминания о запланированных взаимодействиях;
- отчет `Активности клиентов`, сгруппированный по клиентам и отсортированный по дате;
- цветовое оформление отчета: старые события — светло-серые, последние две недели — желтые, будущие — зеленые;
- автоматическое создание демонстрационных данных: 4 клиента, 4 контактных лица и 6 взаимодействий разных видов, включая 2 прошедших;
- проверки обязательного заполнения карточек клиентов, контактов и взаимодействий.

## Структура репозитория

- `src/` — иерархическая выгрузка конфигурации 1С;
- `tools/generate_config.py` — воспроизводимый генератор XML и BSL исходников;
- `tools/build.ps1` — загрузка исходников, обновление базы, проверка и сборка артефактов;
- `build/` — готовые файлы поставки после сборки.

## Сборка

Требуется установленная учебная платформа 1С 8.3.21.1644 и существующая файловая информационная база.

```powershell
python .\tools\generate_config.py
powershell -ExecutionPolicy Bypass -File .\tools\build.ps1 `
  -InfoBasePath "C:\Users\Антон\Downloads\Z1\CRM_Z1"
```

Скрипт загружает `src/`, обновляет конфигурацию базы данных, запускает встроенную проверку и создает `build/CRM_Z1.cf` и `build/CRM_Z1.dt`.

## Проверка вручную

1. Запустить базу в режиме `1С:Предприятие`.
2. Открыть раздел `Продажи`.
3. Проверить списки `Клиенты`, `Контактные лица`, `Взаимодействие`.
4. Открыть отчет `Активности клиентов` и нажать `Сформировать`.

Демонстрационные данные создаются один раз при первом запуске.
